# Patient Management System API

This is a simple Patient Management API built using Python, FastAPI, and Pydantic V2.

## Features
- Create a patient
- View all patients
- Search for a patient by ID
- Update patient details
- Delete a patient
- Sort patients by height, weight, and BMI
- Calculate BMI and BMI category automatically

## Technologies Used
- Python
- FastAPI
- Pydantic V2
- Uvicorn
- JSON

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
uvicorn main:app --reload
```

Open the API documentation:

http://127.0.0.1:8000/docs

## Purpose

This project was created for learning Python, FastAPI, and Pydantic data validation.
